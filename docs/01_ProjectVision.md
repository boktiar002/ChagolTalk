\# ChagolTalk



\## Vision

Build a modern anonymous communication platform that allows users to communicate through text and voice in a secure and scalable environment.



\## Objectives



\- Random matchmaking

\- Real-time messaging

\- Voice communication

\- Friend system

\- Reporting system

\- Admin dashboard



\## Target Audience



Anyone looking to communicate with strangers safely.
